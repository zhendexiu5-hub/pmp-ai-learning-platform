# 01_项目与运营｜答案解析

### KP-FOUND-001 — 答案 B

**解析：** 临时安排并不自动构成项目；工作本质是重复分拣并维持运营。A 把 temporary 误当成 project，C/D 与定义无关。

**标签：** Foundation / F / All / 中

**主要陷阱：** Temporary ≠ Project


### KP-FOUND-002 — 答案 A

**解析：** 它有独特成果、完成状态和移交点。上线后的重复维护才属于运营。

**标签：** Foundation / F / All / 易

**主要陷阱：** 把长期使用误判为运营


### KP-FOUND-003 — 答案 B

**解析：** 重复开展相似工作不排除每次都是独特项目；关键看具体情境和完成状态。

**标签：** Foundation / F / All / 中

**主要陷阱：** 重复 ≠ 运营


### KP-FOUND-004 — 答案 C

**解析：** 2026 强调价值和成果。三重约束不足以单独判定成功；部分收益可能在运营期实现，但必须有指标和责任人。

**标签：** Foundation / F / All / 中

**主要陷阱：** Deliverable ≠ Outcome ≠ Benefit


### KP-FOUND-005 — 答案 C

**解析：** 工作性质不同，Hybrid 可同时满足治理证据和快速反馈；关键是统一接口、风险和价值。

**标签：** Process / PR1 / Hybrid / 中

**主要陷阱：** Hybrid 不是机械各半
