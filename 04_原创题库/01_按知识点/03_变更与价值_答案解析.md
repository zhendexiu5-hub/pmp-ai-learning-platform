# 03_变更与价值｜答案解析

### KP-CHANGE-001 — 答案 B

**解析：** 大小不改变基本控制逻辑：先记录和影响分析，再按授权审批。

**标签：** Business Environment / BE3 / Predictive / 易

**主要陷阱：** 小变更也需控制


### KP-CHANGE-002 — 答案 A

**解析：** 批准后需反映到受影响文件和工作授权，再实施并验证。

**标签：** Business Environment / BE3 / Predictive / 中

**主要陷阱：** 批准 ≠ 自动实施完成


### KP-CHANGE-003 — 答案 B

**解析：** 敏捷变化通常进入 Product Backlog，由 PO 排序；Sprint Backlog 由 Developers 管理。

**标签：** Business Environment / BE3 / Agile / 中

**主要陷阱：** 预测型变更流程套敏捷


### KP-CHANGE-004 — 答案 B

**解析：** 价值导向要求寻找可用、合规且有质量的增量，先验证商业价值。

**标签：** Process / PR3 / All / 中

**主要陷阱：** 增量不是半成品


### KP-CHANGE-005 — 答案 B

**解析：** MVP 的核心是以最小可用产品验证价值，并仍需满足必要质量与合规。

**标签：** Process / PR3 / Agile / 易

**主要陷阱：** MVP ≠ 最低质量
