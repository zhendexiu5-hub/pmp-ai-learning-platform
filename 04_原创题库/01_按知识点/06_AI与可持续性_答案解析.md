# 06_AI与可持续性｜答案解析

### KP-FUT-001 — 答案 B

**解析：** 敏感数据和未批准工具带来隐私、安全与合规风险，应先评估并选择受控方案。

**标签：** AI / Cross-cutting / All / 中

**主要陷阱：** 便利不能绕过数据治理


### KP-FUT-002 — 答案 B

**解析：** AI 可增强分析，但高影响变更需人类监督、证据和正式治理。

**标签：** AI / Cross-cutting / All / 中

**主要陷阱：** Human oversight


### KP-FUT-003 — 答案 B

**解析：** 平均准确率可能掩盖对特定群体的不公平，需要分群验证与治理。

**标签：** AI / Cross-cutting / All / 中

**主要陷阱：** 平均值掩盖偏差


### KP-FUT-004 — 答案 B

**解析：** 生命周期思维避免把交付期节省转化为长期成本和影响。

**标签：** Sustainability / Cross-cutting / All / 中

**主要陷阱：** Lowest price vs Best value


### KP-FUT-005 — 答案 B

**解析：** 可持续性声明需清晰边界、可靠数据、方法和复核。

**标签：** Sustainability / Cross-cutting / All / 中

**主要陷阱：** Greenwashing
