# 04_敏捷角色与事件｜答案解析

### KP-AGILE-001 — 答案 B

**解析：** Developers 对如何完成 Sprint 工作负责；Scrum Master 促进而非分配。

**标签：** Agile / Cross-cutting / Agile / 中

**主要陷阱：** Servant Leadership 不是指挥控制


### KP-AGILE-002 — 答案 B

**解析：** DoD 是所有增量共同质量标准，单条验收标准不能替代它。

**标签：** Agile / Cross-cutting / Agile / 中

**主要陷阱：** AC vs DoD


### KP-AGILE-003 — 答案 A

**解析：** Review 面向产品与价值；Retrospective 面向团队过程改进。

**标签：** Agile / Cross-cutting / Agile / 易

**主要陷阱：** Review vs Retro


### KP-AGILE-004 — 答案 B

**解析：** WIP Limit 促进完成、暴露瓶颈并减少切换。

**标签：** Agile / Cross-cutting / Agile / 中

**主要陷阱：** 忙碌不等于流动


### KP-AGILE-005 — 答案 B

**解析：** Story Point 的尺度依赖团队，不适合跨团队绩效排名。

**标签：** Agile / Cross-cutting / Agile / 中

**主要陷阱：** Story Points ≠ hours/KPI
